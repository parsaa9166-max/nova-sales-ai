# NOVA فروش AI

اپلیکیشن موبایل‌محور برای ساخت محتوای تبلیغاتی حرفه‌ای از روی عکس محصول.

## امکانات

- دریافت عکس از دوربین یا گالری
- تحلیل هوشمند محصول
- ساخت تصویر تبلیغاتی
- تولید عنوان و توضیحات فروش
- کپشن اینستاگرام
- متن استوری
- هشتگ و CTA
- کنترل کیفیت تصویر با AI
- تولید مجدد تصویر با سبک متفاوت
- دانلود تصویر نهایی
- تاریخچه خروجی‌ها

## فناوری

- Next.js 15
- React 19
- Fal.ai
- OpenRouter
- Gemini 2.5 Flash
- Flux 2 Edit
- Docker
- Render
